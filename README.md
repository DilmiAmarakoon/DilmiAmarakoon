## About Me

I’m a **third-year Data Science undergraduate at SLIIT** interested in machine learning, data analytics, and business intelligence. I build projects that turn raw data into dashboards, predictions, and applications people can use.

- **Data analytics and BI:** I work with SQL, dimensional modeling, and Power BI to explore and present data.
- **Machine learning:** I use Python and scikit-learn for data preparation, classification, and model evaluation.
- **Application development:** I’ve worked on interactive data apps, mobile apps, and REST APIs.
